# Reggiws - Homepage

Personal academic homepage and photo collections, hosted with GitHub Pages at https://reggiws.github.io/.

The homepage is a customized version of the [Luka Homepage Template](https://github.com/wzsyyh/luka-homepage-template) by Yuheng Yang. Its license is retained in `LICENSE.md`.

Edit `index.html` for the homepage, `photos/index.html` for the collection menu, and `photos/2025/index.html` or `photos/2026/index.html` for the galleries. Images live in `assets/photos/`. Push to the `v5` branch to deploy.

## School emblem sources

- Chinese Academy of Sciences seal (used for the UCAS entry): [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Seal_of_the_Chinese_Academy_of_Sciences.png).
- Xidian University seal: [Huan Wang's academic homepage](https://hwang52.github.io/image/xdu.png), consistent with the emblem described in [Xidian University's charter](https://www.xidian.edu.cn/xxgk/xxjj1.htm).
- Tsinghua University High School seal: [Sohu education article](https://www.sohu.com/a/551408888_121118943).
